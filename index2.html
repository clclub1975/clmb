🟢 공용 키 사용 중

📌 처음 오셨나요? (AI 사용을 위한 준비)
이용을 위해 구글 AI 열쇠(API Key)가 필요합니다. 우선은 촛불회 공용 키로 자동 설정되어 있습니다.
다만, 공용 키를 다수가 사용할 경우 AI 사용량 한도로 인해 서비스가 제한될 수 있으므로 개인 무료 API Key 사용을 권장합니다.
개인 키를 사용하시려면 [키 삭제하기]를 누른 뒤, 여기(Google AI Studio)를 눌러 로그인하시고 [Create API key]에서 키를 복사해 주세요. 그 후 아래 입력창에 키를 붙여넣고, 저장 버튼을 눌러 [개인 키 저장대기] 상태에서 한 번 더 눌러 저장해 주시면 됩니다! (최초 1회만 설정해두면 기기가 기억합니다.)

⚠️ [주의] 공용 PC에서 개인 API Key를 사용하셨다면, 사용 후에는 반드시 키를 삭제하여 주시기 바랍니다.
