📌 처음 오셨나요? (AI 사용을 위한 준비)
AI 이용을 위해서는 구글 AI 키(API Key)가 필요합니다. 임시로 촛불회 공용 키를 사용할 수 있습니다만(아래의 '키 설치하기' 버튼 꾹), 공용 키를 다수가 사용할 경우, AI 사용량 한도 때문에 서비스가 제한될 수 있습니다. 따라서 개인 무료 API Key 사용을 권장합니다.

💡 초간단 개인 (무료)키 발급 및 설치 방법:
1. 만약 공용 키가 설치되어 있는 상태라면, 먼저 [키 삭제하기] 버튼을 누릅니다.
2. 파란색 글씨의 여기(Google AI Studio)를 눌러 사이트로 이동한 뒤, 로그인 계정이 본인 것인지를 확인합니다.
3. 로그인 계정 확인은 창의 왼쪽 하단(다른 위치일 수도 있음)에서 할 수 있습니다.
4. 만약 본인 계정으로의 변경이 필요하면 ‘계정 전환’ 버튼을 눌러 변경합니다.
5. 화면 우측 상단(또는 중앙)에 있는 [API 키 만들기 (Create API key)] 버튼을 누르면 키가 생성됩니다.
6. 생성된 키의 복사 버튼(📋)을 누른 뒤, 이 페이지로 돌아와 아래 빈 입력창에 붙여넣습니다.
7. 저장 버튼을 누르면 곧바로 저장이 완료됩니다.
8. 최초 1회만 해두면 기기가 기억합니다.

⚠️ [주의] 공용 PC에서 본 화면을 통하여 API 키를 저장해 놓은 상태라면, 사용 후에는 반드시 키를 삭제하여 주시기 바랍니다.
