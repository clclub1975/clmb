촛불회 회보 요약 및 홈페이지 제작 작업 프로세스 v1.2

본 문서는 촛불회 회보 원천 데이터 추출부터 홈페이지 및 서브 페이지 구축까지의 전체 개발 공정을 체계적으로 기록한 현황판입니다.

1. 원천 데이터 추출 및 아카이브 구축 단계

  • 1차 메타데이터 및 전문 추출 (`1_1차추출 프롬프트`): 월간 회보 PDF 파일을 분석하여 핵심 요약 메타데이터와 기고문 전문 아카이브를 분리·수집합니다.
  • 2차 요약 고도화 (`2_2차추출 프롬프트`): 1차로 추출된 내용을 웹사이트 및 AI 활용에 적합하도록 정제하고 체계화합니다.

2. 데이터 시트화 및 경로 자동화 단계

  • 구글 시트 통합 데이터베이스 구축 (`99_data_for_HPtable`): 추출된 모든 회보 데이터를 구글 시트에 집계하여 호수별 유무, 발행년월, 링크 등을 매핑합니다.
  • 파일 경로 및 ID 자동 추출 스크립트 (`4-1_pdfID.js`, `4-2_모든파일PATH.js`): PDF 파일들의 고유 ID와 웹 경로를 스크립트를 통해 자동으로 추출하여 시트 데이터와 연동합니다.

3. 홈페이지 UI 레이아웃 및 프롬프트 고도화 단계

  • 데이터 기반 콘텐츠 생성기 (`5_홈페이지용 데이터 만들기 프롬프터`): 시트 데이터를 활용해 홈페이지 콘텐츠를 일괄 가공합니다.
  • 격자형 테이블 레이아웃 구현 (`6_홈페이지 테이블 채우기1`, `6_홈페이지 테이블 채우기2`): 중첩 테이블 오류를 방지하고, 단일 ``과 `colspan`을 활용한 5열 격자 구조의 홈페이지 메인 화면 코딩 룰을 정립합니다.

    4. 서브 페이지 확장 및 AI 기능 구현 단계

    • 회원별 기고문 전문 보기 및 메뉴 확장 (`7_회원별 기고문 전문보기`, `07_기고문전문보기 메뉴`): 회보 전체 목록 외에 개별 기고문 전문과 스토리, 캘린더 등의 서브 페이지 구현 (`articles.html`, `story.html`, `calendar50.html` 등).
    • AI 추억 스토리 생성기 탑재 (`story.html`): 구글 Gemini API를 연동하여 사용자가 검색 기간과 참고 항목을 선택하고 촛불회보 역사에 대해 질문·답변을 주고받을 수 있는 인터랙티브 페이지를 구축합니다.
