🟢 공용 키 사용 중

📌 처음 오셨나요? (AI 사용을 위한 준비)
AI 이용을 위해서는 구글 AI 키(API Key)가 필요합니다. 임시로 촛불회 공용 키를 사용할 수 있습니다만, 공용 키를 다수가 사용할 경우 한도 초과로 제한될 수 있습니다. 개인 무료 API Key 사용을 권장합니다.

💡 개인 (무료)키 발급 및 설치 방법:
1. 만약 공용 키가 설치되어 있는 상태라면, 먼저 [키 삭제하기] 버튼을 누릅니다.
2. 파란색 글씨의 [여기(Google AI Studio)]를 눌러 사이트로 이동한 뒤, 로그인 계정이 본인 것인지를 확인합니다.
3. 로그인 계정 확인은 창의 왼쪽 하단에서 할 수 있습니다.
4. 화면 우측 상단의 [API 키 만들기 (Create API key)] 버튼을 누르면 키가 생성됩니다.
5. 생성된 키를 복사하여 아래 빈 입력창에 붙여넣고 저장하세요.

⚠️ [주의] 공용 PC에서 본 화면을 통하여 API 키를 저장하셨다면, 사용 후 반드시 키를 삭제해 주세요.
